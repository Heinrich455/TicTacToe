Обычные Крестики-Нолики.

Реализовано три уровня сложности:
1) Легкий - случайные ходы. 
2) Сложный - идеальные ходы. 
3) Средний - смешанные ходы.

Сложный ии реализован через minimax с кэшом, который учитывает симметрии и отражения игрового поля.
Присутствуют unit-тесты.

Технологии:
1) Язык - c# 14
2) Фреймворк - .Net 10
3) UI - Windows Forms
4) Тестирование - xUnit
